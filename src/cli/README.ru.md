# Модуль `cli`
Этот модуль предоставляет входную точку для библиотеки,
чтобы её можно было вызывать, как скрипт. Этот скрипт
принимает параметры и выполняет вск этапы обработки страниц.
Скачанные документы помещаются в папку "Загрузки" текущего
пользователя, если место загрузки не изменено параметром
`--downloads`.

Скрипт можно вызвать двумя способами:
```shell
# Замените на имя интерпретатора на Вашей системе
python3 -m scraper_parser.cli
# или
scraper-parser
```

Доступные параметры можно посмотреть, передав скрипту
параметр `--help`.
