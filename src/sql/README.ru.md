# Папка с исходниками SQL
Эта папка содержит схему и данные для базы данных
с инструкциями для веб-скрапера. Они используются
модулем `database` для инициализации БД, если
пользователь не передал путь к существующей.
 - `instr_schema.sql` содержит схему базы данных
   и предпочитаемые параметры.
 - `instr_data.sql` содержит инструкции, ссылки
   на страницы для скачивания и описания
   HTML-элементов, которые нужно скачать.
